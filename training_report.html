Study design

Dataset

Target and conclusion

The required foundation target was at least 95.00% held-out accuracy. The observed 93.47% result is 1.53 percentage points below target.

Target not met. The model is usable as an initial baseline, but requires further tuning or data augmentation before claiming the foundation pass mark.

Training method

1

Base model
MobileNetV2 pretrained on ImageNet. The pretrained convolutional backbone supplies general visual features.

2

Classifier head
MobileNetV2's final 1,000-class layer was replaced with a 10-class linear layer. Eight epochs trained only this head.

3

Fine-tuning
The final two feature blocks were unfrozen and trained for five epochs at a lower learning rate.

Preprocessing and optimization

Training transforms

224 × 224 random resized crop; random horizontal flip; brightness, contrast and saturation jitter; tensor conversion; ImageNet normalization.

Optimization

Cross-entropy loss; AdamW; weight decay 10⁻⁴; classifier learning rate 10⁻³; fine-tune learning rate 10⁻⁵; batch size 32; seed 42.

Evaluation formulas

Error rate

Interpretation and next improvements

What worked

The pretrained backbone improved rapidly, with validation accuracy rising from 83.96% to 92.64%. Cross-entropy loss fell consistently during classifier training.

What did not work

Fine-tuning the final two blocks initially destabilized training and ended below the classifier-stage best model. The fine-tuning learning rate or unfreezing depth needs revision.

Improve performance

Test stronger augmentation, train one more block instead of two, use label smoothing, reduce or remove dropout, add early stopping, and tune input resolution.

Improve reliability

Run repeated seeds, use stratified class splits, report confusion matrix and per-class F1, and test on PlantDoc field photos to measure generalization beyond lab images.
